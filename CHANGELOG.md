# Changelog

## 1.3.2 — first public release

- **Click the Memory card to see what's using memory.** Each app is shown once with
  all of its processes added up (Chrome, Edge and Teams run dozens). On Windows the
  breakdown also shows **Windows itself** (kernel and drivers) and memory **not
  linked to one app** (compressed memory, graphics, protected system processes), so
  you can see why a fresh Windows start already shows several GB in use.
- Click an app in the breakdown to list just its processes.
- Tested for two days on a Windows laptop (16 GB) and on macOS.
